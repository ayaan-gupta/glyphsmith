# Image requests

5 images requested, 0 delivered.

These are build-time assets. Save each file at the path given and the app picks it up on the next build: `src/ui/assets.ts` globs `assets/generated/` and anything found there replaces the code-drawn version of the same name. Until then the hero is an SVG assembled from the app's own letter strokes (`src/ui/art.tsx`), the posters are painted on a canvas (`src/ui/poster.ts`), and the template is generated by `src/raster/template.ts`.

**Style bible:** warm paper texture, ink-blue linework, lots of whitespace.

**Colours:** paper `#faf6ec`, ink blue `#1b3a73`, guide blue `#b9d3f0`.
